# 🔮 Next Text Predictor — Recurrent Neural Networks

A hands-on deep learning project exploring how Recurrent Neural Networks (RNNs) learn sequential patterns in text to predict what comes next. The project demonstrates the fundamentals of sequence modeling through an interactive text prediction application built with Streamlit.

## 🚀 Live Demo

**[Try the Next Text Predictor](https://aoisynm-next-text-predictor.streamlit.app/)**

Explore how a trained model uses previously entered text to generate a prediction for the next word or text sequence.

## 📌 Project Overview

Natural language consists of sequences in which the order of words matters. Recurrent Neural Networks are designed to process sequential data by retaining information from previous inputs.

This project explores how an RNN learns patterns from text and uses those patterns to predict subsequent text. It provides a practical introduction to sequence modeling and the application of deep learning to language prediction.

## 🎯 Objectives

- Understand the fundamentals of Recurrent Neural Networks.
- Explore sequential data and text preprocessing.
- Learn how neural networks identify patterns in text.
- Train a model to predict subsequent text from an input sequence.

- Deploy an interactive deep learning application using Streamlit.

## ⚙️ Project Workflow

1. **Text Preparation** — Load and prepare the text corpus.
2. **Tokenization** — Convert text into numerical representations.
3. **Sequence Generation** — Create input sequences for model training.
4. **Model Training** — Train an RNN to learn patterns and relationships in sequential text.
5. **Text Prediction** — Use the learned patterns to predict subsequent text.
6. **Deployment** — Provide an interactive interface through Streamlit.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/AOISYNM/DA_Practice.git
cd DA_Practice/RNN
```

### 2. Install Dependencies

```bash
pip install numpy pandas streamlit jupyter tensorflow
```

Install only the dependencies required by your implementation.

### 3. Run the Notebook

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the relevant notebook in the `RNN` directory and execute the cells sequentially.

### 4. Run the Web Application

Navigate to the directory containing the Streamlit application and run:

```bash
streamlit run app.py
```

Replace `app.py` with the actual entry-point filename if it differs.
