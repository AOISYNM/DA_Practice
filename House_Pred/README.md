# 🏠 House Price Prediction

A machine learning project that explores housing data and uses regression techniques to predict house prices based on relevant property features. Built with Python and deployed as an interactive web application using Streamlit.

## 🚀 Live Demo

**[Try the House Price Prediction App](https://aoisynm-house-price-predction.streamlit.app/)**

Make house price predictions directly in your browser using the deployed application.

## 📌 Project Overview

House price prediction is a regression problem that uses historical housing data to estimate property prices. This project demonstrates the process of analyzing housing data, preparing features, building predictive models, and deploying a machine learning application.

## 🎯 Objectives

- Explore and understand housing datasets.
- Clean and preprocess data for machine learning.
- Perform exploratory data analysis (EDA).
- Identify relationships between property features and prices.
- Develop regression models for house price prediction.
- Deploy an interactive prediction application.

## 🛠️ Technologies Used

- **Python** — Core programming language
- **Pandas & NumPy** — Data manipulation and numerical computation
- **Matplotlib & Seaborn** — Data visualization
- **Scikit-learn** — Machine learning and model evaluation
- **Streamlit** — Interactive web application and deployment
- **Jupyter Notebook** — Experimentation and model development

## ⚙️ Project Workflow

1. **Data Preparation** — Load and prepare the housing dataset.
2. **Data Cleaning** — Handle missing values and format features.
3. **Exploratory Data Analysis** — Investigate distributions, patterns, and correlations.
4. **Model Training** — Apply regression techniques to learn from housing data.
5. **Model Evaluation** — Evaluate predictive performance using appropriate regression metrics.
6. **Deployment** — Make house price predictions accessible through a Streamlit web application.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/AOISYNM/DA_Practice.git
cd DA_Practice/House_Pred
```

### 2. Install Dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn streamlit jupyter
```

### 3. Run the Project

Open the relevant Jupyter Notebook in the project directory and execute the cells sequentially.

```bash
jupyter notebook
```

To launch the Streamlit application locally, navigate to the directory containing its Python entry-point file and run:

```bash
streamlit run app.py
```

*Replace `app.py` with the actual application filename if it differs.*
