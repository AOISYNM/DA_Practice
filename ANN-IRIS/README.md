# ANN — Iris Classification

A beginner-friendly Artificial Neural Network (ANN) project using the **Iris dataset** for multi-class classification.

This project is part of my data science and machine learning practice, focusing on understanding the basic workflow of building, training, and evaluating a neural network.

## 📌 Overview

The **Iris dataset** contains measurements of iris flowers from three different species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

The goal of this project is to use an Artificial Neural Network to learn the relationship between the flower measurements and their corresponding species.

## 🧠 What I Practiced

* Loading and exploring the Iris dataset
* Data preprocessing
* Splitting data into training and testing sets
* Feature scaling
* Building an Artificial Neural Network
* Training the model
* Evaluating model performance
* Making predictions

## 📊 Dataset

The Iris dataset contains four input features:

| Feature      | Description         |
| ------------ | ------------------- |
| Sepal Length | Length of the sepal |
| Sepal Width  | Width of the sepal  |
| Petal Length | Length of the petal |
| Petal Width  | Width of the petal  |

The target variable represents the three Iris species.
